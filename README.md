# TUCA — Portal institucional e educativo

Repositório do projeto do Templo de Umbanda Caminhos de Aruanda.

Nesta fase, o trabalho consiste em três protótipos navegáveis para avaliação e aprovação do dirigente. Os conteúdos são demonstrativos e os arquivos originais do logotipo e da fotografia do congá serão preservados.

As propostas serão apresentadas por uma branch e um pull request para revisão. Não há publicação do site, conexão de domínio ou painel administrativo nesta fase.
